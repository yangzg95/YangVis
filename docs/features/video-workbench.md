# 短视频工作台与列表的交互/流程能力

这份文档收口短视频**制作流程**上的一组交互能力：分镜整理、连播自检、问题镜头
定位、草稿片兜底，以及项目列表的检索排序。底层的渲染机制（尾帧链式、TTS 配音、
素材与角色注入）分别见 [video-chain.md](video-chain.md)、
[video-tts.md](video-tts.md)、[materials.md](materials.md)、
[characters.md](characters.md)，这里不重复。

## 分镜整理

- **拖拽排序**：分镜列表整行可拖（原生 HTML5 drag，无第三方依赖），与上下箭头
  共用同一个重排函数；排序结果只改本地顺序，保存后由服务端按数组顺序重算
  `sort_order` 与时间轴 `start_s`，前端不自己抄时间。
- **首帧缩略图与状态点**：每行一个 9:16 首帧缩略图，镜号压左上、作业状态点压
  右下。状态点五态：灰（未渲）、脉冲蓝（在途，含链式「等待第 N 镜」）、红
  （失败/超时/取消）、青（首帧已成）、绿（片段已成）。
- **渲染前「只选待处理」**：首帧/片段两个确认弹窗在「全选/全不选」之外各有一个
  「只选待处理」，一键勾出还没成功、当前也不在途的镜头（片段档还要这一档现在
  发得出去），补渲时不用手动取消一堆勾选。

## 片段连播与问题定位

- **片段连播**：预览区标题栏的「连播片段（N）」按镜头顺序自动接续播放所有成功
  片段，用来在出整片前检查镜间衔接与节奏；从当前选中镜之后开始，播完提示结束，
  手动点别的镜头会中止连播。它只切换预览的 `src`，不产生任何新作业。
- **「待处理」导航**：分镜面板有「待处理」按钮，从当前镜向后（绕回开头）跳到
  第一个首帧/片段未成功的镜头并提示原因。
- **列表页联动**：短视频列表里任一渲染阶段带「需处理」标记的项目，点「工作台」
  会带上 `?attention=1`，工作台落地后自动选中第一个问题镜头；也支持显式
  `?shot=<sort_order>` 定位到指定镜。定位请求只消费一次，详情轮询不会抢走用户
  当前选中。

## 草稿片合成（跳过未完成镜头）

完整合成要求每一镜都有成功片段，一镜失败全片卡死。草稿片是兜底出口：

- 发布区在有镜头缺片段、但至少一镜已成功时出现「合成草稿片（跳过 N 镜）」，
  入队带 `allow_missing=true`。
- 服务端只把**已就绪**的片段按镜头顺序拼起来，跳过的镜号快照进
  `publish_job.request.skipped_shots` 留痕；严格模式（默认）缺片段仍整条拒绝，
  两条口径并存。
- **TTS 时间轴重算**：跳过镜头后保留镜头在拼接片里的位置变了，入队快照按保留
  序列从 0 重新累加每句配音的 `start_s`（而不是用库里按全片累加的 `start_s`），
  否则配音会整体错位。runner 与 ffmpeg composer 不感知草稿，只读重算后的快照，
  因此这部分改动集中在 `compose_publish` / `_tts_snapshot`。
- 一条成功片段都没有时草稿模式也拒绝（不能拼空气）；补齐片段后仍可再合成完整成片。

## 产物复用与字幕导出

- **片段存回素材库**：预览区片段作业旁的「片段存素材」把这一镜成功的视频片段复制一条
  进账号级素材库（名字与分组由服务端按「项目｜第 N 镜片段」定），与首帧「存为素材」
  同一套复制语义——产物按项目分、素材按账号分，删项目不带走库里那条。存进来的是视频类
  素材，本期只记录引用、不参与渲染。
- **台词 SRT**：导出菜单在屏幕文字 SRT/ASS 之外多一个「台词 SRT（TTS 配音校对）」，
  文本源是每镜的台词（TTS 念的那一段）而不是屏幕文字，时间轴与屏幕文字版同一累加口径，
  用来对着成片校对配音。

## 项目列表检索与排序

- `GET /office/videos` 新增 `q`（标题模糊，`%`/`_` 按普通字符转义）与 `order`
  两个查询参数；排序是服务端白名单，非法值回落默认序，不拼 SQL。
- 四档排序：最近更新（默认，`updated_desc`）、最早更新、最新创建、最早创建。
  制作进度筛选仍在前端本地做，与标题搜索正交。

## 实现结构

| 位置 | 职责 |
| --- | --- |
| `backend/app/services/videos/service.py` | `list_projects(keyword, order)` 白名单排序与标题转义；`compose_publish(allow_missing)` 的片段筛选、跳过留痕与 `_tts_snapshot` 起点重算 |
| `backend/app/routers/videos.py` | 列表 `q/order` 查询参数；`compose` 收 `VideoComposeIn` |
| `backend/app/models/schemas.py` | `VideoComposeIn.allow_missing` |
| `frontend/src/views/VideoWorkbench.vue` | 拖拽排序、状态点、连播、待处理导航与 query 定位、只选待处理、草稿片入口与门槛 |
| `frontend/src/views/Videos.vue`（壳）、`components/videos/VideoProjectsPanel.vue` | 三页签壳（片子/人物库/素材库，tab 走 query）；片子页签的标题搜索、排序选择、attention 跳转 |
| `frontend/src/components/videos/CharacterPicker.vue` | 内联简版建档（见 characters.md） |
